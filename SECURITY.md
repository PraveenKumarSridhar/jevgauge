# Reporting security issues

Do not publish keys, prompts, or private logs in an issue. For a suspected credential disclosure or destructive installer behavior, use GitHub's private vulnerability reporting if enabled; otherwise open a minimal issue asking for a private reporting channel without exploit details or sensitive data.

The installer never patches Hermes automatically. It refuses unowned or changed plugin files. Routing sends a bounded initial prompt to the configured HTTPS Jev endpoint as documented in README. Treat that endpoint as a data recipient.
