Sources, assumptions and what is not measured
Synthetic fixture, not live activity
Conversations, prompts, projects, model requests, usage and classifier outcomes are fictional demonstration data. Their API-equivalent costs are calculated using the source-linked OpenAI reference-rate snapshot below. These are not live usage or invoice figures.
Known provider tokens = input + output. Cached input is already within input; reasoning is already within output. Repeated conversation context counts again on each provider request. Missing-usage requests are excluded, not assigned zero. Jev token usage is unavailable, not zero.
The cumulative plot resets to zero at the selected period start. Date filters select conversation completion dates in America/Vancouver and include all usage of those conversations. Individual request timestamps are unavailable in this fixture. Hover values interpolate between daily or monthly totals.
Verified external sources
TypeSafe model pricing, checked September 25, 2026: Jev costs $0.042 per million input tokens; output tokens are free. The fixture uses an arbitrary $0.0015 per call instead. That is not the published rate.
The displayed routing instruction template and current support limits were checked against the local plugin source. Editable instructions, bot routing and additional provider families remain proposed.
Savings calculation
Net estimated savings = baseline minus model-provider cost minus assumed Jev cost. The same known token and cache volumes are repriced against the captured default, median eligible model cost, and highest-capability eligible model. These are API-equivalent scenarios, not causal or cash savings.
Missing usage makes full-period savings incomplete. Manual overrides remain in workload totals. Reasoning effort is not a price multiplier. Project membership is an explicit synthetic assignment, never inferred from a prompt.
Not measured by this preview
This preview has no live data connection. Actual provider and Jev bills, subscription quota savings, bot invocations, and task-quality impact are unavailable here.
Configuration validates draft format only. It does not verify real account eligibility, write Hermes settings, call a provider, or change historical results.
